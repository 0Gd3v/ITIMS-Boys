## Project Summary: Simplex (Transmit-Only) SPI Master
This peripheral is a highly optimized, simplex SPI master controller (Index: 16) specifically designed for high-speed data transmission from the TinyQV CPU to write-only external peripherals.

### Key Features
* **Automatic CS Management**: Hardware-controlled active-low Chip Select (`CS_n`) during standard 8-bit transactions.
* **Configurable Clock Scaling**: Features a 7-bit programmable divider to dynamically support various SPI frequencies based on the system clock.
* **Hardware Status Monitoring**: Provides a dedicated `BUSY` flag (Bit 0 of the STATUS register) for precise CPU synchronization and polling.

### Pinout Mapping
| Signal | Pin | Description |
| :---: | :---: | :--- |
| **SCLK** | `uo_out[0]` | Serial Clock generated by the master. |
| **MOSI** | `uo_out[1]` | Master Out Slave In (Data transmitted to device). |
| **CS_n** | `uo_out[2]` | Active-low Chip Select (Automatically asserted). |

### Register Map
| Address | Name | Access | Description |
| :---: | :---: | :---: | :--- |
| `0x00` | **DATA** | W | Transmit data register (Writing to this address immediately initiates the SPI transaction). |
| `0x01` | **STATUS** | R | Bit 0: `BUSY` flag (1: Transmission in progress, 0: Idle/Ready). |
| `0x02` | **DIVIDER** | W | Clock divider configuration for scaling the SPI `SCLK` period. |

### Testing & Validation
The design underwent rigorous verification using the **cocotb** Python framework, encompassing:
* **Clock Speed Verification**: Asserting that the `BUSY` bit duration accurately scales proportionally with the `DIVIDER` register values.
* **Protocol Timing**: Cycle-accurate confirmation of MSB-first data serialization on the MOSI line.
* **Reset Safety**: Verifying that an asynchronous reset strictly clears the `BUSY` flag and safely pulls `CS_n` High.
