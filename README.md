## Project Summary: Half-Duplex (Transmit-Only) SPI Master
This peripheral is a simplified SPI master controller (Index: 16) designed for high-speed data transmission from the TinyQV CPU to write-only external devices.

### Key Features
- **Automatic CS**: Manages active-low Chip Select automatically during 8-bit transmissions.
- **Configurable Clock**: Features a 7-bit programmable divider to support various SPI frequencies.
- **Status Monitoring**: Provides a hardware **BUSY flag** (Bit 0 of Status Register) for CPU synchronization.

### Pinout Mapping
| Signal | Pin | Description |
|:---:|:---:|:---|
| SCLK | `uo_out[0]` | Serial Clock generated by the master. |
| MOSI | `uo_out[1]` | Master Out Slave In (Data to device). |
| CS_n | `uo_out[2]` | Active-low Chip Select. |

### Register Map
| Address | Name | Access | Description |
|:---:|:---:|:---:|:---|
| `0x00` | **DATA** | W | Transmit data (Writing starts transaction immediately). |
| `0x01` | **STATUS** | R | Bit 0: BUSY flag (1: In progress, 0: Idle). |
| `0x02` | **DIVIDER** | W | Clock divider for SPI period settings. |

- **Clock Speed Verification**: Ensuring BUSY bit timing scales with divider values.
- **Protocol Timing**: Confirming MSB-first data transmission on MOSI.
