# SPI Transmit-Only Controller

- **Author**: Matt
- **Peripheral Index**: 16

## What it does
This peripheral is a simplified SPI master controller designed for high-speed data transmission from the TinyQV CPU to external devices that do not require a return data path (such as simple LED drivers, DACs, or write-only display modes).

The controller manages **8-bit transmissions**. It automatically pulls the Chip Select (`CS`) low when a write occurs to the data register and returns it high once the 8th bit has been shifted out. The transmission speed is fully programmable via an internal clock divider.

## Key Features
- **Automatic CS**: Manages active-low Chip Select without manual CPU toggling.
- **Configurable Clock**: Supports a wide range of SPI frequencies through a 7-bit divider.
- **Status Monitoring**: Provides a hardware `BUSY` flag so the CPU can synchronize transmissions.

## Pinout
The peripheral maps its internal SPI engine to the dedicated Tiny Tapeout output pins (`uo_out`):

| Signal | Pin | Description |
|:---|:---|:---|
| **SCLK** | `uo_out[0]` | Serial Clock generated by the master. |
| **MOSI** | `uo_out[1]` | Master Out Slave In (Data to device). |
| **CS_n** | `uo_out[2]` | Active-low Chip Select. |

## Register Map

| Address | Name | Access | Description |
|:---|:---|:---|:---|
| `0x00` | **DATA** | W | Transmit data. Writing a byte here immediately starts the SPI transaction. |
| `0x01` | **STATUS** | R | Status register. Bit 0 is the `BUSY` flag. |
| `0x02` | **DIVIDER** | W | Clock divider. Sets the SPI clock period relative to the system clock. |

### Control / Status Register (Address `0x01`)

| Bit | Name | Access | Description |
|:---|:---|:---|:---|
| **0** | **BUSY** | R | **High (1)** when transmission is in progress; **Low (0)** when idle. |
| **1-7** | Reserved | R | Returns 0. |

## How to Test
The peripheral is tested using the **cocotb** framework provided in the template.



1.  **Clock Speed Verification**: Use `test_varying_clock_speeds` to ensure the `BUSY` bit timing scales correctly with different divider values.
2.  **Protocol Timing**: Use `test_msb_first_verification` to confirm that the Most Significant Bit (MSB) of the data byte appears on `uo_out[1]` (MOSI) first.
3.  **Reset Safety**: Use `test_reset_during_transmission` to verify that an asynchronous reset immediately pulls `CS_n` high and clears the `BUSY` flag.

## External Hardware
This controller is compatible with any SPI-capable device that supports **3-wire SPI** (CS, CLK, MOSI), including:
* **Shift Registers**: For expanding output ports (e.g., 74HC595).
* **Write-only Displays**: Such as certain OLED or LCD configurations.
* **Digital-to-Analog Converters (DACs)**: For generating analog waveforms.

> **Note**: Since this is a half-duplex transmit-only module, it cannot read data back from sensors (MISO is not implemented in this version).
